Configurar este espelho

Quatro passos, uma ligação direta.

1 · Dá um nome a este destino

Podes preparar o HA2 em Alicante e manter o nome Lisboa quando o mudares de local.

2 · Escolhe onde guardar

Monta primeiro o disco no HA2. Esta app valida a identidade; não monta, formata, desmonta nem desliga discos.

3 · Autoriza Alicante

No Data Steward de origem, abre Configurar espelho → Preparar chaves públicas. Cola o emparelhamento aqui.

4 · Prepara a ligação

É a porta que Alicante usará. No separador Rede da app, expõe a porta interna 2222. Configura manualmente o router ou um encaminhamento TCP. O reverse proxy HTTP do Home Assistant não encaminha SSH.

As alterações ficam guardadas para o próximo arranque. Reinicia manualmente apenas esta app para as aplicar; não é necessário reiniciar o Home Assistant.
